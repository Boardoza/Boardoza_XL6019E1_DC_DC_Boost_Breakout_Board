# Boardoza XL6019E1  DC-DC Boost Converter Breakout Board

The **Boardoza XL6019E1** is a high-efficiency **DC-DC boost converter breakout board** built around the **XL6019E1** switching regulator IC. It is designed to step up low DC input voltages to higher, regulated output voltage levels while maintaining high efficiency and stable operation.

This board is well suited for **industrial electronics, robotics, LED drivers, automotive systems, battery-powered projects, and embedded applications** where higher voltage outputs such as 12V, 24V, 36V, or 48V are required from lower-voltage sources. Its compact size and simple pinout make it ideal for both prototyping and final product integration.

## Key Features

- **Wide Input Voltage Range:** Supports input voltages from **5V to 40V**, allowing operation from a wide variety of DC power sources.
- **Selectable Output Voltage Levels:** Provides regulated, selectable output voltages of **12V, 24V, 36V, or 48V** to suit different system requirements.
- **High-Efficiency Boost Conversion:** Designed for high performance with efficiency levels of up to **94%**, minimizing power loss.
- **Fixed Switching Frequency:** Operates at a stable **180 kHz switching frequency** for predictable and reliable behavior.
- **High Switching Current Capability:** Supports up to **5A internal switching current**, suitable for demanding boost applications.

## Technical Specifications

**Model:** XL6019E1  
**Manufacturer:** Boardoza  
**Manufacturer IC:** XLSEMI   
**Input Voltage:** 5V – 40V  
**Output Voltage:** 12V, 24V, 36V, 48V (Selectable)  
**Converter Type:** DC-DC Boost Converter  
**Maximum Output Current:** Up to 2A (depending on input voltage and operating conditions)  
**Switching Frequency:** 180 kHz  
**Maximum Switching Current:** 5A  
**Operating Temperature:** -40°C to +125°C  
**Board Dimensions:** 40 mm × 40 mm

## Board Pinout

### **( J1 ) Input Connector**

| Pin Number | Pin Name | Description |
|:---:|:---:|---|
| 1 | VIN | Power Input (5V – 40V) |
| 2 | GND | Ground |

### **( J2 ) Output Connector**

| Pin Number | Pin Name | Description |
|:---:|:---:|---|
| 1 | VOUT | Boosted Output Voltage (12V / 24V / 36V / 48V) |
| 2 | GND | Ground |
